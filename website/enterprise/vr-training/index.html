Before we build

Start with
the objective.

What should participants learn, practise or demonstrate? We shape the scope around that goal.

Can we start with a single module?

Yes. We can begin with a focused prototype or training module, then use that work to define the scope of a larger simulation.

Can you use our procedures and equipment models?

We assess your documentation, reference material and existing 3D models during discovery. That establishes what can be reused, what needs adapting and what should be created.

Which devices can it run on?

The device is selected around the participants, operating environment and interactions. We define the target hardware and testing requirements before production.

What determines the development scope?

The number of scenarios, equipment behaviours, environments, interactions and target platforms all affect the scope. Existing materials and integration requirements also shape the work.

How will participants access the simulation?

Distribution is defined for the project: the target devices, where the application will be used and how it will be installed or made available. We prepare the builds for that agreed setup.
